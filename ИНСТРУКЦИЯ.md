# Кладовая — как запустить

Приложение работает и без сервера: всё хранится на телефоне. Сервер (Supabase) нужен, чтобы данные были одинаковыми на телефоне и компьютере и не пропали, если сменишь телефон. Схема та же, что у «Кошачьего журнала».

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | страница приложения и оформление |
| `app.js` | вся логика: хранение, конструктор, рецепты, дневник, закупки, синхронизация |
| `data.js` | справочник продуктов (тара, полки, сроки, калории, шаги готовки) и стартовые рецепты |
| `supabase.js` | библиотека для связи с сервером (та же, что в «Кошачьем журнале») |
| `sw.js`, `manifest.webmanifest`, иконки | чтобы приложение ставилось на экран «Домой» и работало без интернета |
| `setup.sql` | настройка базы Supabase, запускается один раз |

---

## Шаг 1. Новый проект Supabase (≈ 5 минут)

1. Зайди на supabase.com → **New project**. Название: `kladovaya`, регион — любой европейский, пароль базы придумай и сохрани.
2. Подожди, пока проект создастся (1–2 минуты).
3. Слева **SQL Editor** → **New query** → вставь весь текст из файла `setup.sql` → **Run**. Должно появиться «Success».
4. Слева **Authentication** → **Sign In / Providers** → **Email** → выключи **Confirm email** → Save. Иначе после регистрации придётся подтверждать почту письмом.
5. Слева **Project Settings** → **API Keys**. Скопируй:
   - **Project URL** (вида `https://xxxx.supabase.co`)
   - **Publishable key** (начинается с `sb_publishable_`)

## Шаг 2. Вписать ключи в приложение

Открой `index.html` в любом редакторе (Блокнот подойдёт), найди строку

```
<script>window.KL_CONFIG=window.KL_CONFIG||{url:"",key:""};</script>
```

и впиши свои значения между кавычками:

```
<script>window.KL_CONFIG=window.KL_CONFIG||{url:"https://xxxx.supabase.co",key:"sb_publishable_..."};</script>
```

Или пришли мне URL и ключ в чат — впишу сама. Publishable-ключ не секретный: он и так виден в коде любой страницы, а данные защищены правилами доступа из `setup.sql`.

## Шаг 3. GitHub Pages

1. github.com → **New repository** → имя `kladovaya`, **Public** → Create.
2. **Add file → Upload files** → перетащи **все файлы из папки** (кроме этой инструкции — её можно тоже) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save.
4. Через 1–2 минуты приложение откроется по адресу: **https://heylittleworld.github.io/kladovaya/**

## Шаг 4. На iPhone

1. Открой адрес в **Safari** → кнопка «Поделиться» → **На экран «Домой»**.
2. Запусти «Кладовую» с иконки.
3. Вверху справа нажми **☁︎ Вход** → впиши почту и пароль → **Создать аккаунт** → **Создать мой дом и выгрузить данные**.
4. Чтобы посмотреть, как всё работает, можно нажать «Загрузить пример» — положу продукты из макета. Лишнее потом отметишь «Закончилось».

На компьютере открываешь тот же адрес и входишь с той же почтой — данные подтянутся.

## Как обновлять приложение

Когда я пришлю новую версию файлов:
1. Загрузи изменённые файлы в репозиторий (Upload files, они заменят старые).
2. В `sw.js` поменяй номер версии в строке `const V = "kl-v1";` на следующий (`kl-v2`, `kl-v3`…). Это говорит телефону, что пора обновиться.
3. На телефоне закрой приложение и открой снова (иногда нужно дважды).

## Если что-то не так

- **«Почта не подтверждена»** — не выключен Confirm email (шаг 1.4).
- **«Код не найден»** — ошибка в коде приглашения, проверь буквы и цифры.
- **Значок ☁︎ показывает «!»** — открой ☁︎ и посмотри текст ошибки, пришли мне.
- **Бесплатный Supabase засыпает**, если проектом не пользовались неделю: зайди на supabase.com и нажми **Restore**. Данные на телефоне при этом никуда не деваются.
- **Резервная копия:** ☁︎ → «Скачать копию» — файл со всеми данными.
